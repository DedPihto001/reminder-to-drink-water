# Вода по расписанию

## Шаги

1. Утром наполни бутылку 0,5 л и поставь её на стол рядом с монитором.
2. Создай в телефоне будильники на 10:00, 12:00, 15:00 и 17:00.
3. Подпиши каждый сигнал: «Сделай несколько глотков воды».
4. После сигнала выпей несколько глотков и поставь отметку на стикере у монитора.
5. После обеда снова наполни бутылку, если вода закончилась.

## Заметки

- Пей небольшими порциями; не нужно выпивать большой объём за один раз.
- Подстрой сигналы под встречи и свой рабочий график.
- Если будильники отвлекают, используй календарь или стикер на мониторе.

## Как это сделано

- Промпт: роль → контекст → задача → формат JSON.
- Модель: Copilot SDK в VS Code; точная модель в данных этой сессии не указана.
- Temperature: 0.2 — параметр задан в задании, фактическое значение средой не раскрывается.
- max_tokens: 500 — значение задано в задании, фактический лимит средой не раскрывается.
- Итерация: во второй версии уточнена роль и добавлен few-shot пример.

## Запуск приложения-напоминания

В этой папке есть также настольное приложение на Python. Запустите его из
PowerShell (при необходимости сначала создайте окружение):

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python main.py
```

Приложение использует только стандартную библиотеку Python и напоминает через
выбранный интервал (по умолчанию 60 минут).
